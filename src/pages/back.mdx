| Word | What it means |
|---|---|
| AI agent | A program that takes a goal, plans the steps and uses tools to get it done. |
| LLM | Large language model. The AI “brain” that reads, thinks and writes. |
| Tool | Any system an agent is allowed to use, like search, a calendar, a database or payments. |
| Prototype | A first working version that shows an idea can work. |

| Serverless | The cloud looks after the servers. You pay mostly for what you use. |
| Function | A short piece of code that runs when something happens, then stops. |

## Answers

### Chapter 2, Think about it: one account for 5,000 people

- **The bill and the limits.** Every request uses the same account. AI providers limit how many requests one account can make each minute. So at busy times Botley slows down or fails for everyone. And nobody can tell which team spent what.
- **Everything happens as Maya.** There is no record of who really asked for what. And if Maya leaves or her account is closed, Botley stops working for the whole company.

### Chapter 5, Your turn: choose the home

| # | Answer | Why |
|---|---|---|
| 1 | Function | It is short, it starts when an email arrives, and there is no conversation to remember. |
| 2 | Managed agent runtime | Many users, acting for each person, memory and a full record. This is exactly what it is built for. |
| 3 | Console agent | The fastest test with no developers. They can move to a runtime later if it grows. |
| 4 | Kubernetes | They already use it, and running their own AI model needs GPUs and strict control. |
| 5 | Serverless container | It is part of a bigger app, it must be able to move clouds, and it can scale to zero at night. |

### Chapter 8, Your turn: Priya's three messages

- **Same room:** the 9:00 and 9:10 messages. The gap was only 10 minutes, so the room was still waiting.
- **At 9:40, no.** After the 9:10 message there were 30 quiet minutes, more than the 15-minute idle timeout. The room was deleted and wiped, and the history inside it went too.
- **The fix:** keep the conversation outside the room, in AgentCore Memory or a database, filed under Priya's user ID and the session ID.
